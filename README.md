> **Unofficial community project.** Tanka CLI is not an official Tanka product.
> The project is in early development; no CLI release is available yet.

## Why this project?

Tanka CLI aims to bring everyday Tanka workflows into the terminal: working with chats, finding and updating documents, asking AI for help, and connecting these actions to scripts and developer workflows.

We are sharing the project early to find out how many people want it and which capabilities matter most. **Star this repository if you would use a Tanka CLI.**

## What is Tanka?

[Tanka](https://www.tanka.ai/) is an AI-powered team collaboration platform. It brings together communication, documents, and AI assistance, helping teams keep track of conversations, information, and the context behind their work.

Tanka's capabilities include chat, Memo documents, email, calendars, meetings, and AI. Its team memory connects information from conversations and other work materials so AI can help retrieve context, summarize information, and prepare next steps. Visit the [official website](https://www.tanka.ai/) for more about Tanka.

## Planned CLI capabilities

These are development goals, not features available in a published CLI today.

| Area | Planned terminal workflows |
| --- | --- |
| Chat | Send messages, browse conversations, and read message history. |
| Documents | List, search, create, and update Memo documents. |
| AI | Ask questions, summarize information, and draft content with Tanka AI. |
| Contacts and groups | Find people and navigate team conversations. |
| Calendar | View schedules and work with events. |
| More collaboration tools | Gradually add files, meetings, polls, and other Tanka capabilities. |

The public release scope is **the CLI version**. Specific commands and supported capabilities will be documented as development progresses.

## The 1,000-star milestone

**When this repository reaches 1,000 GitHub stars, we plan to make the first CLI version available.**

Stars help us measure demand and decide how to prioritize development. Release details and installation instructions will be announced in this repository. There is no download or installation command yet.
