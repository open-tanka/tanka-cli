> **非官方社区项目。** Tanka CLI 并非 Tanka 官方产品。
> 项目目前处于立项与早期开发阶段，尚未发布可用的 CLI 版本。

## 为什么做这个项目？

我们希望把 Tanka 的日常操作带到终端：收发聊天消息、查找和编辑文档、调用 AI，并把这些能力接入脚本和开发工作流。

现在公开项目，是为了了解有多少人需要 Tanka CLI，以及大家最想解决什么问题。**如果你也想在终端里使用 Tanka，欢迎点一个 Star。**

## Tanka 是做什么的？

[Tanka](https://www.tanka.ai/) 是一个结合 AI 的团队协作平台，把沟通、文档与 AI 助手放在一起，帮助团队保留工作中的信息、讨论和上下文。

Tanka 提供聊天、Memo 文档、邮件、日历、会议和 AI 等能力。它的团队记忆能够串联对话及其他工作资料，让 AI 帮助查找背景、总结信息和准备下一步工作。更多产品信息可查看 [Tanka 官网](https://www.tanka.ai/)。

## CLI 计划支持哪些能力？

以下是开发规划，尚不代表已有公开发布、可以安装使用的 CLI。

| 能力 | 计划在终端中完成的操作 |
| --- | --- |
| 聊天 | 发送消息、查看会话、读取聊天历史。 |
| 文档 | 列出、搜索、创建和编辑 Memo 文档。 |
| AI | 向 Tanka AI 提问、总结信息、辅助撰写内容。 |
| 联系人与群组 | 查找联系人、查看团队会话。 |
| 日历 | 查看日程、操作日历事件。 |
| 更多协作能力 | 逐步接入文件、会议、投票等 Tanka 能力。 |

本项目对外开放的范围是 **CLI 版本**，具体命令和能力支持情况会随着开发进展补充到文档中。

## 1,000 Star 目标

**当本仓库达到 1,000 个 GitHub Star，我们计划开放首个 CLI 版本。**

Star 用于帮助我们判断实际需求、安排开发优先级。版本发布方式和安装说明会在本仓库公布；目前还没有可下载的版本或安装命令。

## 一起决定 CLI 的方向

1. **点一个 Star**，让我们知道你需要 Tanka CLI。
2. **[分享使用场景](https://github.com/open-tanka/tanka-cli/issues/new?template=use-case.yml)**：你最想在终端里完成什么？
3. **[参与需求讨论](https://github.com/open-tanka/tanka-cli/issues)**，告诉我们哪些工作流应该优先支持。
4. **[加入 Discord 社区](https://discord.gg/U37HzChGa)**，交流使用场景、分享想法、关注开发进展。

反馈时可以描述你需要的 Tanka 能力、使用的操作系统，以及希望完成的任务或自动化流程。
